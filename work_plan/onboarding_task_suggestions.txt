Task 1 Detail: Geospatial semantic embedding (multimodal)

The idea is to build a small end-to-end proof-of-concept that embeds geospatial imagery and its associated text/metadata into a shared vector space, so you can search across modalities (e.g., find an image tile by describing it in text, or vice versa).

Why this task first: It's a good onboarding task because it's self-contained, doesn't require deep familiarity with the rest of the codebase yet, and forces you to touch the actual geospatial data the project works with early on.

Suggested steps:
1. Get a sample dataset. Pull a small subset of the project's geospatial data — satellite/aerial imagery tiles paired with descriptive text or metadata (captions, location names, land-use tags, etc.).
2. Pick a pretrained multimodal model. Start with something off-the-shelf rather than training from scratch — CLIP, or a remote-sensing-specific variant if one exists (e.g., RemoteCLIP, GeoCLIP, SkyCLIP) tend to perform much better on satellite imagery than generic CLIP.
3. Embed both modalities. Run the image encoder over your image tiles and the text encoder over the paired metadata/captions, producing vectors in the same space.
4. Build a tiny retrieval index. Store the embeddings (a flat numpy array or FAISS index is enough at this scale).
5. Sanity-check retrieval. Query with a text description ("flooded agricultural field") and confirm the nearest image embeddings make sense — and the reverse (image to nearest text).
6. Write up findings. Note where retrieval fails (e.g., ambiguous terrain, rare classes) — this becomes useful signal for whether the project needs a domain-adapted encoder rather than a generic one (ties into Task 3).

Deliverable: a short script/notebook plus a few example queries with results, plus notes on embedding quality and any domain gaps observed.

Step 1 Detail: Dataset for Task 1 (Geospatial semantic embedding)

Recommended dataset: RSICD (Remote Sensing Image Captioning Dataset)
- ~10,921 remote sensing images collected from Google Earth, Baidu Map, MapABC, and Tianditu.
- Each image has up to 5 human-written captions (text metadata) describing the scene.
- Images are 224x224 RGB, covering categories like airports, farmland, bridges, forests, etc.
- Matches the "imagery + text pairs" format needed for Task 1.

How to get it:
- Easiest path, Hugging Face `datasets` library, no manual download/extraction needed:
    from datasets import load_dataset
    ds = load_dataset("arampacha/rsicd")
  (alternative: "danielz01/rsicd" if that one has issues)
- Original source repo (with links to Google Drive / Baidu Pan for raw files):
  https://github.com/201528014227051/RSICD_optimal
- Reference for later steps: published CLIP-RSICD fine-tuning example and walkthrough:
  https://huggingface.co/flax-community/clip-rsicd-v2
  https://huggingface.co/blog/fine-tune-clip-rsicd

Suggested exploration once downloaded:
- Load a handful of images and print their captions.
- Check class/category balance (some categories are much more represented than others).
- Note image resolution and any preprocessing needed before feeding into a CLIP-style encoder.

Step 2 Detail: Pretrained model for Task 1 (Geospatial semantic embedding)

Recommended model: RemoteCLIP
- A vision-language foundation model for remote sensing, from the paper "RemoteCLIP: A Vision Language Foundation Model for Remote Sensing" (IEEE TGRS).
- Built on the OpenCLIP architecture, fine-tuned on remote sensing image-text pairs (should embed RSICD much better than generic CLIP).
- Available in three sizes: RN50, ViT-B-32, ViT-L-14. ViT-B-32 is a good starting point (smaller/faster than ViT-L-14, better than RN50).

How to download it:
    pip install open-clip-torch huggingface_hub

    from huggingface_hub import hf_hub_download

    checkpoint_path = hf_hub_download(
        "chendelong/RemoteCLIP",
        "RemoteCLIP-ViT-B-32.pt",
        cache_dir="checkpoints"
    )
    print(f"Downloaded to {checkpoint_path}")

How to load it with OpenCLIP:
    import open_clip
    import torch

    model, _, preprocess = open_clip.create_model_and_transforms("ViT-B-32", pretrained=None)
    tokenizer = open_clip.get_tokenizer("ViT-B-32")

    ckpt = torch.load(checkpoint_path, map_location="cpu")
    model.load_state_dict(ckpt)
    model.eval()

From there, encode RSICD images with model.encode_image(...) and captions with model.encode_text(...) to produce the shared embedding space needed for step 3.
